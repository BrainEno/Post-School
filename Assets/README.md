# Unity assets

Only approved source assets belong here. Unity-generated `.meta` files are expected and must be versioned with their assets.

Do not copy Godot `.import` sidecars, `.godot/`, or editor caches. Before importing an asset from Where Is School, review its exact source entry in [the original asset provenance ledger](https://github.com/BrainEno/where-is-school/blob/main/docs/ASSET_PROVENANCE.md) and record the Unity-side decision in `docs/ASSET_PROVENANCE.md`.
